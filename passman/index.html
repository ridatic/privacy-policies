Politique de confidentialité — Passman

Dernière mise à jour : juin 2026

1. Résumé

Passman est un gestionnaire de mots de passe conçu pour protéger votre vie privée. Toutes vos données sont chiffrées localement sur votre appareil. Votre mot de passe maître ne quitte jamais votre appareil.

2. Données collectées

Passman ne collecte aucune donnée personnelle sans votre consentement explicite.

  • Données du coffre-fort : stockées localement, chiffrées en AES-256-CBC avec votre mot de passe maître. Passman n'a aucun accès à ces données.
  • Synchronisation cloud (optionnelle) : si vous activez la synchronisation Firebase, le coffre-fort chiffré est stocké dans votre espace Firebase. Seul vous pouvez le déchiffrer avec votre mot de passe maître.

3. Données NON collectées

  • Aucune analyse comportementale
  • Aucune publicité
  • Aucun tracking
  • Aucun partage avec des tiers
  • Votre mot de passe maître n'est jamais transmis

4. Synchronisation Firebase (optionnelle)

Si vous choisissez d'utiliser la synchronisation cloud :

  • Votre adresse e-mail Firebase est utilisée pour l'authentification
  • Le coffre-fort chiffré (illisible sans votre mot de passe maître) est stocké dans Firebase Firestore
  • Firebase est soumis à la politique de confidentialité de Google

5. Permissions Android

  • Biométrie : pour le déverrouillage par empreinte/face (optionnel)
  • Internet : uniquement pour la synchronisation Firebase (optionnel)
  • Stockage : pour l'import/export de fichiers .psm
  • Notifications : pour vous alerter des mots de passe arrivant à expiration (optionnel, Android 13+)

6. Sécurité

Chiffrement AES-256-CBC + PBKDF2-SHA256 (100 000 itérations). Le sel cryptographique est unique par installation. Aucune donnée sensible n'est transmise en clair.

7. Droits des utilisateurs

Vous pouvez supprimer toutes vos données à tout moment depuis l'application (Paramètres → Réinitialiser le coffre) ou en désinstallant l'application.
